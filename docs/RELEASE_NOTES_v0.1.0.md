# v0.1.0 — Public Preview

Source: independent Next.js/React/ECharts frontend and FastAPI/PostgreSQL local research terminal. Static showcase: Overview, Inflation, Labor, Treasury curve, four-chart Workspace, descriptive Analytics, verified selected Fed history, Sources, About/Data Status and explicit Business Cycle limitations.

Includes English/Chinese, Light/Dark/System selection, UTC-linked cursor/zoom, browser workspace settings, Ctrl+K search and CSV/JSON/PNG exports. Original data snapshot generated 2026-11-18 UTC: 13 reviewed series and 17,192 records, retrieved directly from BLS and Federal Reserve Board. Data and software notices are separate from the MIT code grant.

No live backend, real-time sync, ALFRED vintages, complete FOMC chronology, NBER overlays or forecasting are hosted. The full local terminal retains those supported research/data workflows. Browser/OS checks not yet completed remain explicitly marked in docs/ACCEPTANCE.md.

Install/run: see README.md and docs/LOCAL_DEVELOPMENT.md. Online demo: NOT DEPLOYED YET; replace only after actual Cloudflare success and public verification.
